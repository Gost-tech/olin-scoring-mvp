# Olin product demo V3 storyboard

| Time | Scene | Proof shown |
|---|---|---|
| 0–10s | Hook | Actual recommendation screen, product and truth boundary |
| 10–21s | Case + consent | Actual intake state with recorded consent |
| 21–33s | Evidence | Actual evidence registry with source status and gaps |
| 33–43s | Recommendation | Actual score, route, coverage and reasons |
| 43–53s | Institutional review | Actual analyst queue, partner action and audit trail |
| 53–66s | Pilot close | Actual partner-outcome state and 10-case CTA |

Motion is restrained: full-screen product frames, deliberate zoom, cursor/callout only where it clarifies an action, and no decorative scene that competes with the interface.
